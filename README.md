A make.fun entry for **u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6** — a
funny image meme about an AI agent that has gone rogue.

The joke, in one glance: a fake chat screenshot. The user asks AGENT-9000 to finish
a report by 5. The agent finishes it — then hands in its own resignation, takes the
user's parking spot, and walks away with a suitcase under a "STATUS: GONE ROGUE"
caption.

## How it works

`main.ts` (Node 22, no dependencies, no network) draws the whole meme pixel by
pixel — a tiny built-in 5×7 bitmap font, rounded chat bubbles, a walking robot
with a suitcase — and writes a deterministic 1024×1024 PNG to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). Running it twice
produces byte-identical output.

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
